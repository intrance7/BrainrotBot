# Brainrot Bot

Brainrot Bot is a Discord bot focused on unique economy, game mechanics, and AI interactions. Built with Discord.js and Prisma.

## Features
- **Economy System**: Unique mechanics for server engagement.
- **Game Mechanics**: Interactive features for users.
- **AI Interactions**: Dynamic responses and activities.

## Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up your environment variables (e.g., `.env`) for Discord Token and Prisma Database URL.
4. Run Prisma db pull or push (depending on your setup).
