# Command Specification

This document defines every Discord slash command.

## /based
**Purpose:** Give a random based score.
**Input:** `target`: optional user
**Output:** 🔥 @Trance is 87% BASED
**Effects:**
- Aura: +5 to +15
- XP: +10
