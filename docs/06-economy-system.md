# Economy System

Define the currency.
**Currency:** $BRAIN

**Users earn it through:**
- Daily reward
- Commands
- Quests
- Events
- Achievements
- Mini-games

**Spend it on:**
- Items
- Cosmetics
- Profile upgrades
- Titles
- Temporary buffs

**Example Item:**
🥤 Infinite Coffee
Cost: 5,000 BRAIN
Effect: Coffee does not decay for 24 hours.
